# Dentist OS — Product Landing

Marketing landing for **Dentist OS**, the dental-clinic operating system by
[Beyond Pixells](https://somilsharma2000.github.io/beyond-pixells/). Deployed at
https://somilsharma2000.github.io/dentist-os-site/

The working demo clinic (SmileCraft) lives in the separate
[dentist-os](https://github.com/somilsharma2000/dentist-os) repo:
https://somilsharma2000.github.io/dentist-os/

## Design
Single-file landing (`index.html`) using the shared Beyond Pixells design system
(`bp-design-system.css` + `bp-motion.js`), Dentist OS flavor: calm trust, clinical
cyan-green accent family, dark premium canvas.

## Sources
- Research: `beyond-pixells/docs/research/dentist_os.md` (competitors, market,
  buyer psychology, pricing approach, conversion hooks)
- Pricing tiers are research-recommended and await founder confirmation.

## Rules (from the studio handover)
- Never break the design language — shared tokens only, one accent family per page.
- Never invent proof — honest labels only ("live", "demo").
- Verify after every deploy: curl the live URL and grep for your change.
